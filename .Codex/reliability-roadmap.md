## Local validation

- Full `make test`: all 2,974 discovered Swift tests passed after the universal build. The suite includes the busy-menu and stalled-writer recovery regressions. Opt-in real inference/visual tests skip in this ordinary unit run; actual inference was exercised separately.
- Python: 88 tests passed across correction sanitization (19), cache/loading (18), RPC (36), and verification scripts (15).
- Universal `make build` passed at source commit `ea18f8a`. App and uv both contain arm64 and x86_64; the final uv signature verifies and its SHA-256 matches compiled metadata. This is a local development bundle without a Developer ID/notarization.
- After removing obsolete deadline metadata, all 17 focused daemon/transport checks passed and the final app was rebuilt.
- Strict SwiftLint: zero violations across 399 files. Strict Python typing: 11 source files passed.
- Real Parakeet: one actual speech test passed in 36.2 seconds, including pinned-model download/bootstrap/inference.
- Real Whisper/MLX: two actual fixtures passed. Whisper returned “The quick brown fox jumps over the lazy dog.” and correction changed “Their going to the store tomorow.” to “They are going to the store tomorrow.”
- Representative latest timing: explicit runtime refresh 0.668 s, warm reuse 0.00110 s; correction inference 1.366 s; Whisper first/warm transcription 0.834/0.079 s on already compiled models. An earlier first CoreML load took 8.257 s. These are local observations, not product-wide latency guarantees.
- [Actual MLX memory benchmark](bench/model_memory.py) ([recorded results](bench/model-memory-results.json)) alternates pinned Qwen 4B and Gemma 1B models four times. Cache entries remained one, weak references proved replaced models were released, and active MLX memory tracked the selected weights (2,264,693,768 → 735,852,808 bytes). After final release, active memory was 8 bytes and allocator cache 0; RSS fell from 3.11 GB at the first Qwen load to 0.80 GB after release. RSS includes interpreter/library/allocator overhead and does not equal model weight size.

Real-engine checks downloaded public Parakeet v3, Whisper Base, Qwen correction and Gemma benchmark weights into the existing model caches. They did not reset permissions or grant new microphone/Accessibility access. Unit integration tests use synthetic bundled speech, isolated preferences and an isolated delivery store.

## Native verification boundary

The old running app's Dashboard was successfully inspected after Finder opened the repository app bundle. It lacked the new Setup sidebar and therefore was not evidence of the changed build. Later app/Finder observations returned `cgWindowNotFound`; attaching to T3 Code itself timed out. This is an automation connection limitation, not proof that AudioWhisper hung. The earlier layout previews remain previews.

Required final native checks: incomplete Setup, repeated request attempts, microphone denial/recovery, missing selected model, interrupted download/retry, menu and configured-key start/stop, cancel/re-record, captured paste destination, Dashboard/History behavior on desktop and full-screen Spaces, keyboard model selection, VoiceOver and Reduce Motion.
