## Signing reference

[Apple's code identity documentation](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements) explains why ad-hoc designated requirements are tied to an individual build. [Apple's code-signing guide](https://developer.apple.com/library/archive/documentation/Security/Conceptual/CodeSigningGuide/Procedures/Procedures.html) documents certificate-bound identity for local signing without requiring a system trust-policy change.

Apple's macOS SDK `AVAudioIONode.h` documents that the engine's I/O nodes communicate with the system default input/output devices. [Input-node documentation](https://developer.apple.com/documentation/avfaudio/avaudioengine/inputnode) describes the engine-created singleton and hardware format checks. This supports leaving System default routing to the engine; the live error alone does not prove which HAL operation failed.
